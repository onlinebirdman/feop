# usage

### install

```bash
pnpm install pont-preset -D
```

### init

```bash
npx pont-preset init
`
```

### config pont

[pont](https://github.com/alibaba/pont)
[pont documents](https://github.com/alibaba/pont/blob/HEAD/docs/pontConfig.md)

```json
{
  "originUrl": "your swagger url",
  "templatePath": "./pontTemplate",
  "outDir": "../src/api",
  "surrounding": "typeScript"
}
```
